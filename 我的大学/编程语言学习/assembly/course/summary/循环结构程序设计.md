# 循环结构程序设计

>*将ALPHA数组送入100个 ’a' *
>赋值操作，循环次数已知
```assembly
;条件转移指令实现循环
	mov cx,100
	mov si,0
sso:
	mov ALPHA[si],'a'
	inc si
	dec cx
	jnz sso
```

```assembly
;用loop指令实现循环
	mov cx,100
	mov si,0
sso:
	mov ALPHA[si],'a'
	inc si
	loop sso

```

```assembly
;用串处理rep前缀实现循环
mov cx,100
mov di,offset ALPHA
mov al,'a'
rep stosb
```
